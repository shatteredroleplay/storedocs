# Configuration

Every setting lives in the `config` folder. These files are not escrowed, so you can change all of them.

| File | What it holds |
| ---- | ------------- |
| `config/main.lua` | Locale, currency, bridges, chips, UI colour, admin access and rate limit |
| `config/economy.lua` | House pool, cashier, house income, rigging and statistics |
| `config/locations.lua` | Cashiers, the casino centre and the casino zone |
| `config/atmosphere.lua` | Blip, crowd sound, video wall, chip HUD and IPLs |
| `config/server.lua` | Server-only secrets: society account, Discord webhooks and Fivemanage token |
| `config/games/*.lua` | One file per game |
